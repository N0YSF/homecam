# HomeCam

Local configuration experiments for a small network camera setup.

This project contains configuration files and small utilities I used
while experimenting with a camera in my room.

The goal was mainly to understand how different image, stream and
storage settings affected the camera during local testing.

## Features

- Camera configuration profiles
- Image quality presets
- Stream configuration
- Local storage settings
- Configuration validation
- Profile export

## Requirements

- Python 3.x
- PyYAML

Install dependencies:

```bash
pip install -r requirements.txt
