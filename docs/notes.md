# Notes

## Image quality

The default profile was good enough for normal use.

Increasing the bitrate helped with movement but produced larger files
than expected.

## Night testing

The night profile works better when the room lighting is low.

Noise reduction is useful, although too much of it makes small details
look soft.

## Stream settings

The secondary stream is useful when a lower resolution is needed.

Keeping the primary stream on TCP made local testing more consistent
on my network.

## Storage

I originally considered keeping everything remotely, but local
retention was simpler for testing.

The current configuration keeps approximately two weeks of snapshots.

## Hardware

The camera was mainly used for testing different configuration
profiles rather than as a serious security system.

Some of the settings in this repository may therefore be specific to
the device I was experimenting with.
